# 你的天才同学 · Your Brilliant Classmate

作者某老牌中九在读，已有两年深度使用 AI 辅助学习的经验。在这个过程中，我一直希望能有一个真正贴合国内大学生体制、大学生需求的 Skill，把课堂ppt资料、课后作业和期末备考连起来。这也是「你的天才同学」的初衷：从最真实的大学学习场景出发，做一个懂你的、帮你的 AI 同学。

## 核心能力

从**输入**和**输出**两个角度出发，把你上传的课程资料与平时的学习过程连接起来。

### 输入：从你的课程资料中学习，梳理课堂重点

国内大学课堂中，最常见的学习资料是课本电子版、每节课的 PPT 和课堂小测。上传这些资料后，天才同学会检索、阅读和核对相关内容，整理知识点之间的联系，再结合老师的明确要求、课件中的强调和小测考查的内容，梳理有依据的课堂重点。

| 你提供的资料 | 天才同学如何使用 |
| --- | --- |
| **课本电子版** | 建立章节与知识点索引，查找定义、公式、适用条件和例题，作为后续讲解的依据。 |
| **每节课的 PPT** | 对照教材整理课堂内容，保留老师使用的符号、方法和约定，梳理课堂强调的知识点。 |
| **课堂小测** | 将题目对应到知识点，结合课堂资料分析考查内容；有作答记录时，再了解你在这些知识点上的实际表现。 |

### 输出：答疑、检查作业、个性化期末复习

#### 1. 答疑：从原文出发，留下可回看的学习记录

遇到不懂的知识点或题目时，天才同学会先检索你已经上传的教材、课件和小测，尽量引用相关原文，沿用课程中的符号和方法解释。每次知识讲解与解题回答都会附上相关知识点的**原文截图和准确页码或幻灯片编号**，方便你对照理解、回到资料中查阅。

每次提问及其对应的知识点也会被记录下来，逐步汇总成可查阅的学习记录。到了期末，你可以回看自己在哪些地方问过、卡过，哪些问题已经解决，哪些还需要进一步巩固。是否掌握不牢固，会结合实际作答与后续表现判断。

#### 2. 检查作业：通过你的解题思路，找到具体错因

检查作业时，天才同学会围绕出错或存疑的步骤，逐步询问你当时是怎么想的：为什么选这个公式？怎样理解这个条件？这一步是如何推出来的？根据你的回答继续追问，区分知识点缺失、概念理解错误、适用条件误用、解题方法选择、审题或计算操作等具体原因。

确认错因后，再结合课程原文截图解释和纠正，安排有针对性的练习，并记录相关知识点、错因和后续表现，帮助你知道该补什么、怎样补。

#### 3. 期末复习：把平时的提问与错题变成个性化复习依据

课程资料、课堂重点、提问记录、作业表现和已确认的错因，会按课程持续整理到**本地学习数据库**中。期末复习时，天才同学会综合这些记录、老师给出的考试范围和你的可用时间，整理薄弱点、安排复习顺序，并提供适合这门课的练习。

复习过程中产生的新作答和进步也会继续记录，用来调整后续任务，让复习贴合你当前的掌握情况。

不同课程的资料和学习记录分别保存。后续对话能访问原来的课程目录时，就能接着读取已有记录、继续学习。

## 安装与快速开始

### 1. 安装到 Codex

1. 下载本仓库并解压，或克隆到本地。
2. 将完整的 `your-brilliant-classmate` 文件夹放入用户技能目录 `~/.agents/skills/`，保留其中的 `references/`、`scripts/` 和 `agents/`。
3. 在 Codex 中输入 `$`，选择“你的天才同学”，或直接在消息中使用 `$your-brilliant-classmate`。若尚未出现，重启 Codex 后再查看。

Windows 的用户技能目录通常是 `%USERPROFILE%\.agents\skills\`；macOS 和 Linux 为 `~/.agents/skills/`。安装后，目录结构应为：

```text
~/.agents/skills/
└── your-brilliant-classmate/
    ├── SKILL.md
    ├── agents/
    ├── references/
    └── scripts/
```

安装位置与技能调用方式参见 [Codex 官方技能文档](https://developers.openai.com/codex/skills/)。

### 2. 准备课程资料

打开用于这门课的工作目录，提供教材 PDF、老师的课件、课程大纲或作业。先从当前章节开始也可以；一并提供老师给出的考试范围或评分标准，有助于贴近课程要求。

运行随附的 Python 工具需要 Python 3；PDF、PPTX 和图片处理分别使用 PyMuPDF、python-pptx 和 Pillow。如果你的环境尚未提供这些依赖，可在用于运行工具的 Python 环境中安装：

```shell
python -m pip install pymupdf python-pptx Pillow
```

PPT/PPTX 的原文截图需要先用可用的演示文稿工具导出为 PDF 或图片；直接提供导出的 PDF 也可以。扫描版教材的检索效果取决于可用的 OCR 和页面识读能力。

### 3. 开始一起学习

**刚开始一门课：整理资料与学习重点**

```text
使用 $your-brilliant-classmate。这是我的教材、老师的课件和课程大纲。
请先整理课程结构和当前章节的知识点，根据资料梳理学习重点，
说明已经检查了哪些内容，并为这门课建立学习记录。
```

**遇到不会的题：讲解知识并检查思路**

```text
使用 $your-brilliant-classmate。我在这道作业题上卡住了。
请先了解我的解题思路，再帮我检查具体步骤，沿用教材和老师的方法解释，
展示相关原文截图并标注页码，记录已经确认的问题。
```

**准备期末：把平时的记录用起来**

```text
使用 $your-brilliant-classmate。距离这门课的期末考试还有两周，每天能学一小时。
请结合我提供的考试范围、课程资料和已保存的学习记录，
安排复习顺序与每天的任务，优先巩固已确认的薄弱点，并用练习检查掌握情况。
```

后续继续学习时，打开原来的课程工作目录；如果换了目录或对话，提供保存的课程文件路径，方便读取已有资料和记录。
